Query 生命週期速查表

fresh → stale → inactive → removed

兩個設定，管兩件不同的事

設定 控制什麼 預設值
staleTime fresh → stale 的時間；fresh 期間不會背景重抓 0（立刻 stale）
gcTime inactive 之後，資料還能留在快取多久 5 分鐘

經驗法則

  • 「怎麼一直重打 API」→ 先看 staleTime，預設是 0，資料一到手就 stale。
  • 「明明有快取過，怎麼回來還是 loading」→ 檢查是不是超過 gcTime，資料被整個清掉了。
  • TkDodo 原話：gcTime 幾乎很少需要動；真正常調的是 staleTime。
